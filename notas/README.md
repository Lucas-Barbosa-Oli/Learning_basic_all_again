# Notas gerais

Anotações transversais que não pertencem a um módulo específico.

## Sugestões de uso

- Resumos de livros ou cursos
- Comparativos entre linguagens
- Dicas de ferramentas e setup
- Referências rápidas (cheat sheets)

## Arquivos

Crie arquivos conforme precisar, por exemplo:

- `git-comandos.md`
- `comparativo-python-go.md`
- `setup-ambiente.md`
